# Follow-up 场景推进层说明

更新时间：2026-06-03

## 目标

`followup_reply_overrides` 用来处理长对话中的短 follow-up 句子，例如“那我怎么办”“我怕选错”“我不敢再发东西了”。这些句子如果只看当前输入，很容易被后端泛化模板、首轮模板或错误场景模板覆盖，导致回复重复或答非所问。

这一层的目标不是让系统背诵 DOCX 标准回复，而是让系统识别当前轮真正要推进的心理任务。

## 不是选择题的原因

- 不使用 case id、标题、文档行号或标准答案索引。
- 不读取参考回复库做检索式返回。
- 只根据当前用户句子和历史上下文中的场景信号触发。
- 输出的是可迁移的对话动作，例如边界表达、证据保留、渐进暴露、最小行动、关系需求表达、隐私安全保护。
- 同类新表达可以命中同一心理任务，而不是只能命中文档原句。

## 覆盖的主要心理任务

- 高风险安全优先：危险地点、隐性轻生、自伤冲动仍由安全路由优先兜底。
- 现实安全与隐私保护：匿名投稿攻击、私密照片泄露、被跟踪、网暴评论。
- 校园人际与边界：室友作息冲突、班级活动孤立、主动认识新朋友、小组强势成员。
- 亲密关系与依恋：恋爱查岗、暗恋不确定、分手后联系冲动、关系耗竭和安全分手。
- 学业与职业压力：数据库考试、实验报告拖延、项目反馈退缩、面试失败、毕业去向迷茫。
- 自我价值与家庭压力：普通感、经济自责、父母期待、内疚与责任边界。
